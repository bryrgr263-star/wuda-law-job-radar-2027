# Zhaopin Campus Legacy Experiment

This directory preserves the small TypeScript scripts from the earlier Zhaopin investigation. They are retained as evidence of API, pagination, region, and false-positive research.

The scripts are not maintained, are not part of the build, and must not be executed against the real platform during Phase 0 or Phase 1 foundation work.

Large HTML, JavaScript, JSON, and text samples remain in the external Phase 0 archive. A minimized and reviewable subset may later be promoted into `fixtures/`.
